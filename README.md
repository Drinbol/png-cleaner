# PNG文件批量删除脚本

一个用于批量删除PNG文件的Python脚本，根据文件大小规则保留特定文件。

## 功能描述

该脚本用于清理PNG文件，根据以下规则：
1. 保留所有大于50KB的PNG文件
2. 对于每个大于50KB的文件，同时保留其带一个下划线的版本（例如：`a.png` > 50KB，则保留`a.png`和`a_.png`）
3. 删除其他所有小于50KB且没有对应大于50KB版本的PNG文件

## 使用场景

假设你有一组PNG文件，其中：
- 有些是高质量的大文件（>50KB）
- 有些是这些大文件的缩略图或预览版本（文件名相同但多一个下划线）
- 其他是一些不需要的小文件

这个脚本可以帮助你自动清理，只保留重要文件。

## 安装要求

- Python 3.6+
- 无需额外依赖

## 使用方法

### 基本用法
```bash
python main.py 文件夹路径
```

### 示例
```bash
# 处理当前目录下的PNG文件
python main.py .

# 处理指定目录
python main.py /path/to/images

# 模拟运行（只显示将要删除的文件，不实际删除）
python main.py /path/to/images --dry-run

# 显示详细信息
python main.py /path/to/images --verbose
```

### 命令行参数
- `folder`：要处理的文件夹路径（必需）
- `--dry-run`：模拟运行，显示将要删除的文件但不实际删除
- `--verbose`：显示详细信息，包括文件大小和保留原因

## 示例场景

假设你有以下文件：
```
a.png       71KB  (大于50KB，保留)
a_.png      12KB  (a.png的下划线版本，保留)
b.png       45KB  (小于50KB，删除)
c.png       60KB  (大于50KB，保留)
c_.png      15KB  (c.png的下划线版本，保留)
d.png       30KB  (小于50KB，删除)
e_.png      20KB  (没有对应的大文件，删除)
```

运行脚本后：
- 保留：`a.png`, `a_.png`, `c.png`, `c_.png`
- 删除：`b.png`, `d.png`, `e_.png`

## 脚本特点

1. **安全第一**：删除前会要求用户确认（除非使用`--dry-run`）
2. **递归搜索**：会处理指定文件夹及其子文件夹中的所有PNG文件
3. **大小写敏感**：同时处理`.png`和`.PNG`扩展名
4. **详细日志**：可以显示每个文件的大小和操作原因
5. **错误处理**：检查文件夹是否存在，处理权限问题等

## 注意事项

1. **备份重要文件**：在运行删除操作前，建议先使用`--dry-run`参数查看将要删除的文件
2. **文件命名规则**：脚本假设下划线版本的文件名格式为`原文件名_`（例如`a.png`对应`a_.png`）
3. **文件大小**：50KB阈值是硬编码的，如果需要修改可以编辑源代码
